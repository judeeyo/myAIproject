KTX 자동 예매 - 처음 사용하는 분을 위한 설명서 (v1.7)

명령어를 몰라도 됩니다. 내려받기, 압축 풀기, 더블클릭만 하면 됩니다.
Mac을 쓰면 [A]를, Windows를 쓰면 [B]를 따라 하세요.
설정 화면 사용법은 [C]에 있습니다.


==============================================================
[A] Mac
==============================================================

A-1. 프로그램 내려받기
  1) Safari나 Chrome 주소창에 아래 주소를 입력합니다.
     https://github.com/judeeyo/myAIproject/raw/claude/intelligent-goldberg-qmk7ii/downloads/ktx-reserve-final.zip
  2) 'ktx-reserve-final.zip' 파일이 '다운로드' 폴더에 저장됩니다.

A-2. 압축 풀기
  1) Finder를 열고 왼쪽에서 '다운로드'를 누릅니다.
  2) ktx-reserve-final.zip을 더블클릭합니다.
  3) 'ktx-reserve' 폴더가 생깁니다. 이 폴더를 엽니다.

A-3. 실행하기
  1) 폴더 안의 'start.command'를 더블클릭합니다.
  2) 검은(또는 흰) 글씨 창이 열립니다. 이 창이 프로그램입니다. 닫지 마세요.
  3) 처음 한 번은 필요한 프로그램을 설치합니다. 1~3분 기다리세요.
  4) 설치가 끝나면 브라우저에 설정 화면이 자동으로 열립니다.

  경고 창이 나올 때
  - "확인되지 않은 개발자가 배포했기 때문에 열 수 없습니다"
    start.command를 마우스 오른쪽 버튼(또는 control 키를 누른 채 클릭)으로 누르고
    '열기'를 고른 뒤, 다시 나오는 창에서 '열기'를 누릅니다.
  - '열기' 버튼이 없을 때
    화면 왼쪽 위 사과 메뉴 → 시스템 설정 → 개인정보 보호 및 보안으로 갑니다.
    아래쪽 'start.command' 항목 옆의 '그래도 열기'를 누르고 다시 더블클릭합니다.

A-4. 추가 설치 안내가 나올 때 (처음 한 번만)
  - Python 설치 페이지가 열린 경우
    1) 페이지의 노란색 'Download Python 3.x.x' 버튼을 누릅니다.
    2) 내려받은 파일(python-3.x.x-macos11.pkg)을 더블클릭합니다.
    3) '계속' → '계속' → '동의' → '설치'를 누르고 Mac 비밀번호를 입력합니다.
    4) 설치가 끝나면 start.command를 다시 더블클릭합니다.
  - "명령어 라인 개발자 도구를 설치하겠습니까?" 창이 나온 경우
    '설치' → '동의'를 누르고 끝날 때까지 기다린 뒤 start.command를 다시 더블클릭합니다.

A-5. 다음부터
  ktx-reserve 폴더의 start.command를 더블클릭하면 바로 설정 화면이 열립니다.
  폴더를 찾기 쉽게 '응용 프로그램'이나 '문서' 폴더로 옮겨 두어도 됩니다.
  (옮긴 뒤 처음 실행할 때 설치를 한 번 더 합니다.)

A-6. 끄기
  열려 있는 글씨 창을 닫습니다. "프로세스를 종료하겠습니까?"가 나오면 '종료'를 누릅니다.


==============================================================
[B] Windows
==============================================================

B-1. 프로그램 내려받기
  1) Edge나 Chrome 주소창에 아래 주소를 입력합니다.
     https://github.com/judeeyo/myAIproject/raw/claude/intelligent-goldberg-qmk7ii/downloads/KTX_WINDOWS_FIXED.zip
  2) 'KTX_WINDOWS_FIXED.zip' 파일이 '다운로드' 폴더에 저장됩니다.

B-2. 압축 풀기
  1) 파일 탐색기를 열고 왼쪽에서 '다운로드'를 누릅니다.
  2) KTX_WINDOWS_FIXED.zip을 마우스 오른쪽 버튼으로 누르고 '압축 풀기'(또는 '모두 압축 풀기')를 고릅니다.
  3) '압축 풀기'를 누르면 'KTX_WINDOWS' 폴더가 생깁니다. 이 폴더를 엽니다.
  ZIP 파일 안에서 바로 실행하면 동작하지 않습니다. 꼭 압축을 먼저 푸세요.

B-3. 실행하기
  1) 폴더 안의 'start'(start.bat)를 더블클릭합니다.
     파일 종류가 'Windows 배치 파일'인 것이 맞습니다.
  2) 검은 창이 열립니다. 이 창이 프로그램입니다. 닫지 마세요.
  3) 처음 한 번은 필요한 프로그램을 설치합니다. 1~3분 기다리세요.
  4) 설치가 끝나면 브라우저에 설정 화면이 자동으로 열립니다.

  경고 창이 나올 때
  - "Windows의 PC 보호" 파란 창: '추가 정보'를 누르고 '실행'을 누릅니다.
  - "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?": '예'를 누릅니다.

B-4. 추가 설치 안내가 나올 때 (처음 한 번만)
  프로그램이 Python과 Git을 자동으로 설치합니다. 설치가 끝나면
  "Finish the installation, then double-click start.bat again." 이라고 나옵니다.
  아무 키나 눌러 창을 닫고 start를 다시 더블클릭합니다.

  자동 설치가 안 되고 웹페이지가 열린 경우
  - Python 페이지: 노란색 'Download Python 3.x.x' 버튼 → 내려받은 파일 실행
    → 첫 화면 아래 'Add python.exe to PATH'를 꼭 체크 → 'Install Now'
  - Git 페이지: 'Click here to download' → 내려받은 파일 실행 → 'Next'를 계속 누르고 'Install'
  - 둘 다 설치한 뒤 start를 다시 더블클릭합니다.

B-5. 다음부터
  KTX_WINDOWS 폴더의 start를 더블클릭하면 바로 설정 화면이 열립니다.
  바탕화면에 바로가기를 만들어 두면 편합니다.
  (start를 오른쪽 버튼으로 누르고 '바로 가기 만들기' → 만든 바로가기를 바탕화면으로 옮김)

B-6. 끄기
  열려 있는 검은 창을 닫습니다.


==============================================================
[C] 설정 화면 쓰는 법 (Mac, Windows 같음)
==============================================================

화면 왼쪽의 1~4번을 위에서부터 채우고, 화면 아래쪽 파란 [예매 시작]을 누릅니다.

  1 코레일 계정   코레일 아이디(회원번호, 이메일, 휴대폰 번호)와 비밀번호
                  비밀번호가 틀리면 바로 멈춥니다. 5번 틀리면 코레일이 계정을 잠급니다.
  2 처리 방식     처음에는 '테스트'로 한 번 해 보세요. 예약하지 않고 동작만 확인합니다.
                  잘 되면 '예약까지'로 바꿉니다. 결제는 코레일톡 앱에서 직접 합니다.
  3 여정          출발역, 도착역, 날짜, 출발 시간대, 인원
  4 조건          KTX만 탈지, 일반실·특실 중 무엇을 원하는지

예약이 되면
  - 화면 오른쪽과 알림에 열차, 좌석, 결제기한이 나옵니다.
  - 약 10분 안에 코레일톡 앱에서 결제하세요. 늦으면 예약이 자동 취소됩니다.

기다리는 동안
  - 프로그램 창(글씨 창)과 컴퓨터를 켜 두세요. Mac은 덮개를 열어 두세요.
  - 멈추려면 화면의 [중지]를 누릅니다.

더 자세한 화면 설명은 '사용설명서.txt'(Windows는 MANUAL.txt)에 있습니다.


==============================================================
[D] 새 버전으로 바꾸기
==============================================================

위 내려받기 주소에서 ZIP을 다시 받아 압축을 풀고 같은 방법으로 실행합니다.
새 폴더에서 처음 실행할 때 설치를 한 번 더 합니다(1~3분).
역, 날짜 같은 화면 설정은 브라우저가 기억하므로 다시 입력하지 않아도 됩니다.


==============================================================
[E] 안 될 때
==============================================================

- 설정 화면이 안 열린다
  브라우저 주소창에 http://127.0.0.1:3939 를 입력합니다.
- "역 이름 오류"
  출발역·도착역 칸이 비었거나 이름이 다릅니다. 칸을 누르면 나오는 목록에서 고르세요.
- "로그인 실패"
  아이디와 비밀번호를 확인한 뒤 다시 시작하세요. 틀린 비밀번호로 여러 번 시도하지 마세요.
- 창에 빨간 글씨나 "failed" 오류가 나오고 멈췄다
  창의 글씨를 사진으로 찍어 담당자에게 보내 주세요.

본인 탑승용으로만 쓰세요. 되팔기 목적의 매크로 예매는 철도사업법 위반입니다.

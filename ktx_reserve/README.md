# ktx_reserve — KTX 빈자리 자동 예매 (pykorail 기반)

[ktx-auto](https://github.com/ShinbaramEbaksa/ktx-auto)의 예매 루프를 그대로 옮긴 터미널용 스크립트입니다.
ktx-auto는 2026-10-28 코레일톡 7.1.0 업데이트 이후 `-8204`(최신 버전으로 업데이트) 오류로 막혔습니다.
이 스크립트는 7.1.0에 대응한 [pykorail](https://github.com/devgyurak/pykorail)로 코레일과 통신합니다.

## 설치 (맥)

pykorail은 **파이썬 3.11 이상**이 필요합니다. 먼저 버전을 확인합니다.

```bash
python3 --version
```

3.11 미만이면 Homebrew로 설치하세요.

```bash
brew install python
```

그다음 pykorail을 설치합니다.

```bash
python3 -m pip install -U pykorail
```

## 사용법

먼저 `--dry-run`으로 시험합니다. 빈자리를 찾으면 예약하지 않고 멈춥니다.

```bash
python3 ktx_reserve.py --dep 서울 --arr 동대구 --date 2026-11-06 --from 13:00 --to 15:00 --adult 2 --dry-run
```

실제로 예약하려면 `--dry-run`을 빼고 실행합니다. 결제는 앱에서 직접 합니다.

```bash
python3 ktx_reserve.py --dep 서울 --arr 동대구 --date 2026-11-06 --from 13:00 --to 15:00 --adult 2 --adjacent
```

실행하면 코레일 아이디와 비밀번호를 물어봅니다. 비밀번호는 화면에 표시되지 않고 파일로 저장되지 않습니다.
환경변수 `KORAIL_ID`, `KORAIL_PASSWORD`를 설정해 두면 묻지 않습니다. 멈추려면 `Ctrl + C`를 누릅니다.

| 옵션 | 설명 | 기본값 |
|---|---|---|
| `--dep` / `--arr` | 출발역 / 도착역 이름 | (필수) |
| `--date` | 출발일 `2026-11-06` | (필수) |
| `--from` / `--to` | 이 시각부터 ~ 이 시각까지 출발하는 열차 | (필수) |
| `--adult` / `--child` / `--senior` | 어른 / 어린이 / 경로 인원 | 1 / 0 / 0 |
| `--train` | `ktx` `all` `saemaeul` `mugunghwa` `itx-cheongchun` | `ktx` |
| `--seat` | `general-only` `general-first` `special-only` `special-first` | `general-first` |
| `--adjacent` | 2명 이상일 때 붙은 자리만 (아니면 취소 후 계속) | 끔 |
| `--trains` | 이 열차번호만 노림 (예: `105,107`) | 전부 |
| `--interval-min` / `--interval-max` | 조회 간격(초), 이 사이에서 무작위 | 1.0 / 2.0 |
| `--pay` | 예약 후 카드 결제까지 자동 진행 (카드 정보를 실행 시 입력) | 끔 |
| `--dry-run` | 빈자리를 찾으면 예약하지 않고 멈춤 | 끔 |

## ktx-auto와 같은 점, 다른 점

같은 점

- 로그인 실패(아이디/비밀번호 오류)는 즉시 멈춥니다. 계정 잠금을 막기 위해서입니다.
- 로그인 일시 오류는 30초 → 최대 2분 간격으로 재시도하고, 5회 연속이면 10분 간격으로 바꿉니다.
- 세션이 만료되면 다시 로그인합니다. `MACRO ERROR`가 나오면 60초 쉬고, 통신 오류가 나면 5초 쉽니다.
- 붙은 자리 판정 규칙이 같습니다. 같은 호차, 같은 열에서 알파벳이 연속(15A·15B)이거나 번호가 연속이어야 합니다.
- 예약에 성공하면 알림을 보냅니다. 결제에 실패해도 예약은 유지됩니다.

다른 점

- **화면이 없습니다.** 터미널에서 옵션으로 설정합니다.
- **알림은 맥 알림 센터로 옵니다.** 웹 푸시는 쓰지 않습니다.
- **예약 방식은 "조회 후 예약"만 지원합니다.** ktx-auto의 기본값은 조회 없이 예약을 반복해서 보내는 방식입니다.
  pykorail의 예약 함수는 조회 결과의 좌석 정보로 등급을 고르기 때문에, 조회한 뒤 예약하는 방식이 안전합니다.
- **코레일이 이용제한(`-2000`)을 걸면 즉시 멈춥니다.** 반복 요청하면 안 되는 상황이기 때문입니다.
- 붙은 자리가 아니어서 취소한 열차는 60초 동안 건너뜁니다. 예약과 취소를 반복하지 않기 위해서입니다.
- 예약대기로 잡히면 취소하고 계속합니다.
- 실행할 때마다 다른 기기로 보이지 않도록, 가상 기기 정보를 `~/.ktx_reserve/device.json`에 저장해 재사용합니다.

## 주의

- 조회 간격을 너무 짧게 하지 마세요. 코레일은 매크로 적발 시 1회 30분, 2회 1개월 예매 정지, 3회 강제 탈퇴를 안내합니다.
- 결제기한은 예약 후 약 10분입니다(출발 20분 전부터는 5분). 기한 안에 결제하지 않으면 자동 취소됩니다.
- 본인 탑승용으로만 쓰세요. 되팔기 목적의 매크로 예매는 철도사업법 위반입니다. pykorail도 상업적 이용을 금지합니다.
- 코레일이 앱을 다시 업데이트하면 pykorail 업데이트가 필요할 수 있습니다: `python3 -m pip install -U pykorail`

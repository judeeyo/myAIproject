KTX 자동 예매 사용설명서 (v1.7, 2026-11-18)

빈자리가 나면 바로 예약하는 개인용 프로그램입니다.
설정은 브라우저 화면에서 하고, 예매는 이 PC에서 실행됩니다.


[1. 준비물]

- Mac 또는 Windows PC, 인터넷 연결
- 코레일 회원 계정 (회원번호, 이메일, 휴대폰 번호 중 하나)
- Python 3.11 이상, Git
  없으면 처음 실행할 때 설치를 시도합니다. 자동 설치가 안 되면 아래 주소에서 직접 설치하세요.
  Python: https://www.python.org/downloads/
  Git(Windows): https://git-scm.com/download/win
  Git(Mac): 터미널에서 xcode-select --install


[2. 처음 실행]

1) 프로그램 받기
   Git으로 받기(추천):
     git clone https://github.com/judeeyo/myAIproject.git
   또는 ZIP 파일을 받아 압축을 풉니다. ZIP 안에서 바로 실행하지 마세요.

2) 실행 파일 더블클릭
   Mac: start.command
   Windows: start.bat

   처음 한 번은 필요한 프로그램을 설치합니다(1~3분).
   설치가 끝나면 설정 화면이 브라우저에 열립니다.
   화면이 안 열리면 브라우저 주소창에 http://127.0.0.1:3939 를 입력하세요.

3) 보안 경고가 나올 때
   Mac '확인되지 않은 개발자': start.command 우클릭 → 열기 → 열기
   Windows 'PC 보호': 추가 정보 → 실행

다음부터는 더블클릭하면 설치 없이 바로 화면이 열립니다.
이미 켜져 있으면 열려 있는 화면을 다시 보여줍니다.


[3. 화면 사용법]

화면 왼쪽 1~4번을 위에서부터 채우고, 아래쪽 [예매 시작]을 누릅니다.

1 코레일 계정
  아이디와 비밀번호를 입력합니다.
  비밀번호가 틀리면 바로 멈춥니다. 코레일은 5번 틀리면 계정을 잠급니다.

2 처리 방식
  예약까지   좌석을 잡으면 알림을 보냅니다. 결제는 코레일톡 앱에서 직접 합니다.
  결제까지   좌석을 잡으면 카드 결제를 한 번 시도합니다. 카드 정보 입력란이 나타납니다.
  테스트     로그인하고 빈자리를 찾지만 예약하지 않고 멈춥니다.
  데모       코레일에 접속하지 않고 모의 데이터로 화면을 연습합니다.

3 여정
  출발역·도착역(기본값 서울→동대구), 출발일, 출발 시간대, 인원을 정합니다.
  출발역과 도착역은 코레일 표기와 같아야 합니다. 예: 서울, 동대구, 광주송정
  가운데 ⇄ 버튼으로 출발역과 도착역을 바꿉니다.
  시간대는 '이 시각부터 ~ 이 시각까지' 출발하는 열차만 노립니다.

4 조건
  열차 종류: KTX, 전체, 새마을, 무궁화, ITX-청춘
  좌석: 일반실만, 일반실 우선, 특실만, 특실 우선
  배치: 2명 이상이면 '붙은 자리만'을 고를 수 있습니다.
  고급 설정: 특정 열차번호만 노리기, 조회 간격(기본 1~2초)

오른쪽 상태판
  조회 횟수, 마지막 조회 시각, 조회된 열차가 보입니다. 초록색 열차는 빈자리가 있는 열차입니다.
  [조회만 테스트]는 로그인 없이 열차 조회가 되는지만 확인합니다.
  [PC 알림 켜기]를 누르면 예약 결과가 바탕화면 알림으로도 옵니다.

로그
  진행 상황이 시간순으로 나옵니다. 초록색은 성공, 노란색은 주의, 빨간색은 오류입니다.

입력값 기억
  역, 날짜, 인원 같은 설정은 브라우저가 기억합니다.
  비밀번호와 카드 정보는 저장하지 않습니다. 화면을 닫거나 새로고침하면 다시 입력해야 합니다.


[4. 예약이 된 뒤]

- 로그와 알림에 열차, 좌석, 예약번호, 결제기한이 나옵니다.
- 결제기한은 예약 후 약 10분입니다(출발 20분 전부터는 5분).
  기한 안에 결제하지 않으면 코레일이 예약을 자동 취소합니다.
- '결제까지'로 실행했으면 코레일톡 앱의 승차권 확인에서 발권 여부를 확인하세요.
  자동 결제 결과가 불분명하면 다시 시도하지 않고 멈춥니다. 앱에서 상태를 먼저 확인하세요.


[5. 실행 중 주의]

- 실행 창(Mac 터미널, Windows 검은 창)을 닫으면 프로그램이 멈춥니다.
- PC가 잠들지 않게 하세요. Mac은 덮개를 열어 두세요.
- 멈추려면 화면의 [중지]를 누르거나 실행 창을 닫습니다.
- 조회 간격을 줄이지 마세요. 코레일은 매크로가 적발되면 1회 30분, 2회 1개월 예매 정지,
  3회 강제 탈퇴를 안내합니다.


[6. 최신 버전으로 업데이트]

Git으로 받았다면 실행 창을 닫고 프로그램 폴더에서 아래 명령을 실행합니다.
  git pull
그다음 start.command(Windows는 start.bat)를 다시 실행합니다.
화면이 예전 그대로면 브라우저에서 새로고침합니다(Mac Cmd+Shift+R, Windows Ctrl+Shift+R).
ZIP으로 받았다면 새 ZIP을 받아 다시 압축을 풉니다.


[7. 자주 나는 오류]

- 역 이름 오류: 존재하지 않는 역입니다
  출발역·도착역 칸이 비었거나 표기가 다릅니다. 목록에서 고르세요.
- 코레일 앱 버전 거절(-8204)
  코레일이 앱을 업데이트해 프로그램이 막힌 상태입니다. 업데이트를 기다려야 합니다.
- 로그인 실패
  아이디와 비밀번호를 확인한 뒤 다시 시작하세요. 틀린 비밀번호로 여러 번 시도하지 마세요.
- 안티매크로 감지
  60초 쉬었다가 자동으로 계속합니다. 자주 나오면 조회 간격을 늘리세요.
- 포트를 다른 프로그램이 쓰고 있습니다
  다른 프로그램이 3939번 포트를 쓰고 있습니다. 그 프로그램을 끄고 다시 실행하세요.
- 설치 실패 (Python, Git 관련)
  위 [1. 준비물]의 주소에서 직접 설치하고, 실행 창을 완전히 닫았다가 다시 실행하세요.
- 기존 .venv가 오래된 Python이라는 안내
  ktx_reserve 폴더 안의 .venv 폴더 이름을 .venv-old로 바꾸고 다시 실행하세요.


[8. 선택: Discord 휴대폰 알림]

예약 결과를 휴대폰 Discord로 받을 수 있습니다.
1) Discord 본인 서버의 텍스트 채널에서 채널 편집 → 연동 → 웹훅 → 새 웹훅 → URL 복사
2) 프로그램 폴더(ktx_reserve)에서 실행
   Mac:     .venv/bin/python discord_notify.py --setup
   Windows: discord.bat --setup
3) 복사한 URL을 붙여넣습니다(화면에 표시되지 않음).
4) --setup 대신 --test로 실행하면 시험 메시지를 보냅니다.
카드 정보와 예약번호는 보내지 않습니다.


[9. 터미널로 직접 실행 (고급)]

화면 없이 명령으로 실행할 수도 있습니다. ktx_reserve 폴더에서:
  Mac:     bash run.sh --dep 서울 --arr 동대구 --date 2026-12-01 --from 13:00 --to 15:00 --adult 2
  Windows: run.bat --dep 서울 --arr 동대구 --date 2026-12-01 --from 13:00 --to 15:00 --adult 2
전체 옵션은 bash run.sh --help 로 봅니다.
